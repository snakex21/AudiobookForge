AudiobookForge 1.0.6 ships ffmpeg with the app, keeps your data out of the install folder and makes uninstalling safe.

## English

### ffmpeg is now included
- The installer and the portable zip contain `ffmpeg\ffmpeg.exe`, so you no longer need to install ffmpeg or add it to `PATH`.
- Bundled build: FFmpeg `n9.0.2-39-g7adfbe40dc-20261031` (9.0 release branch), the **LGPL v3** static build from FFmpeg-Builds (formerly BtbN/FFmpeg-Builds), without GPL or nonfree components. AudiobookForge stays MIT-licensed; ffmpeg runs as a separate, unmodified program.
- The ffmpeg license is in `ffmpeg\LICENSE.txt`; source links, version and checksums are in `THIRD_PARTY_NOTICES.md`.
- Lookup order: bundled `ffmpeg\ffmpeg.exe` next to the app, then `"ffmpeg_path"` from `config.json`, then `PATH`. Each candidate is tested with `ffmpeg -version`, so a broken one is skipped.
- ffmpeg calls have hard timeouts (5 min per chunk conversion, 60 min for the final merge), so a stuck ffmpeg can no longer hang a job.
- Removed hardcoded ffmpeg paths from the author's machine.

### Your data stays yours
- Installed builds keep settings in `%APPDATA%\AudiobookForge\config.json`, Piper voices in `%LOCALAPPDATA%\AudiobookForge\piper_models` and audiobooks in `Documents\AudiobookForge` (or the folder you choose). Your old `config.json` from the install folder is copied over on first start.
- Uninstalling removes only program files. Settings, voice models and audiobooks are kept; an interactive uninstall asks whether to keep the settings.
- The install folder is no longer writable by every user (removed the `users-modify` permission; upgrades reset it).

### Other changes
- Installer, window title and header show the real version (1.0.6).
- Faster PDF extraction and TTS: the PDF document and Piper voice are reused for the whole job; resumed jobs no longer reuse stale audio chunks.
- System language detection no longer uses the deprecated `locale.getdefaultlocale()`.

### Assets
- `AudiobookForgeSetup.exe`: installer (includes ffmpeg)
- `AudiobookForge-1.0.6-win64-portable.zip`: portable folder build (includes ffmpeg); unzip and run `AudiobookForge\AudiobookForge.exe`
- `SHA256SUMS.txt`: SHA-256 checksums of both files

The single-file `AudiobookForge.exe` from earlier releases is replaced by the portable zip, because the folder build starts faster and can ship ffmpeg next to the app.

## Polski

### ffmpeg jest teraz w zestawie
- Instalator i wersja przenośna (zip) zawierają `ffmpeg\ffmpeg.exe`. Nie trzeba już instalować ffmpeg ani dodawać go do `PATH`.
- Dołączona kompilacja: FFmpeg `n9.0.2-39-g7adfbe40dc-20261031` (gałąź wydań 9.0), statyczna kompilacja **LGPL v3** z FFmpeg-Builds (dawniej BtbN/FFmpeg-Builds), bez komponentów GPL i nonfree. AudiobookForge pozostaje na licencji MIT; ffmpeg działa jako osobny, niezmodyfikowany program.
- Licencja ffmpeg jest w `ffmpeg\LICENSE.txt`, a linki do źródeł, wersja i sumy kontrolne w `THIRD_PARTY_NOTICES.md`.
- Kolejność wyszukiwania: dołączony `ffmpeg\ffmpeg.exe` obok aplikacji, potem `"ffmpeg_path"` z `config.json`, potem `PATH`. Każdy kandydat jest sprawdzany przez `ffmpeg -version`, więc niedziałający zostaje pominięty.
- Wywołania ffmpeg mają twarde limity czasu (5 min na konwersję fragmentu, 60 min na końcowe łączenie), więc zawieszony ffmpeg nie blokuje już zadania.
- Usunięto zaszyte ścieżki do ffmpeg z komputera autora.

### Twoje dane zostają u Ciebie
- Wersja instalowana trzyma ustawienia w `%APPDATA%\AudiobookForge\config.json`, głosy Piper w `%LOCALAPPDATA%\AudiobookForge\piper_models`, a audiobooki w `Dokumenty\AudiobookForge` (albo w wybranym folderze). Stary `config.json` z folderu instalacji jest kopiowany przy pierwszym uruchomieniu.
- Deinstalacja usuwa tylko pliki programu. Ustawienia, modele głosów i audiobooki zostają; deinstalacja interaktywna pyta, czy zachować ustawienia.
- Folder instalacji nie jest już zapisywalny dla każdego użytkownika (usunięto uprawnienie `users-modify`; aktualizacja je resetuje).

### Inne zmiany
- Instalator, tytuł okna i nagłówek pokazują prawdziwą wersję (1.0.6).
- Szybsza ekstrakcja PDF i TTS: dokument PDF i głos Piper są używane ponownie przez całe zadanie; wznowione zadania nie biorą już nieaktualnych fragmentów audio.
- Wykrywanie języka systemu nie używa już przestarzałego `locale.getdefaultlocale()`.

### Pliki
- `AudiobookForgeSetup.exe`: instalator (z ffmpeg)
- `AudiobookForge-1.0.6-win64-portable.zip`: wersja przenośna (folder, z ffmpeg); rozpakuj i uruchom `AudiobookForge\AudiobookForge.exe`
- `SHA256SUMS.txt`: sumy SHA-256 obu plików

Jednoplikowy `AudiobookForge.exe` z poprzednich wydań zastępuje zip przenośny, bo wersja folderowa startuje szybciej i może mieć ffmpeg obok aplikacji.
